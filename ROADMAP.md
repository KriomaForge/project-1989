# Project 1989 — Development Roadmap

## Completed through v1.6 Beta
- Four divisions, fictional squads, basic cups and promotions
- Management careers and board/job changes
- Transfer shortlists, squad tactics, league statistics
- Living Notebook narrative with coach, chairman, press and players
- Retro pixel match incident replay, separate static incident clock
- Expanded manager log, retro league/cup presentation and illustrated menu

## v1.7 — Quality and beta playtesting
- Desktop and mobile playtesting on Chrome, Edge and Safari
- Regression tests for each season transition and cup result
- Accessibility: keyboard controls, reduced motion, narrow mobile testing
- Test and refine story frequency; avoid repetitive events
- More season and career statistics; reliable save-file migrations

## v1.8 — Deepen the football world
- Persistent player relationships, board promises with deadlines
- Supporter reactions / fan commentary (opt-in or bounded frequency)
- Transfer negotiations rather than instant signings
- More authentic 1989–90 cup rules and calendar

## v1.9 — Match animation pass
- Crosses, through balls, set pieces and identifiable goalkeeper actions
- Better sprite movement mapped to the actual recorded event
- Optional interactive shooting mode for showcase incidents

## v2.0 — Release candidate
- Historical research and balancing
- Mobile and usability sign-off
- Official changelog, documentation and error reporting strategy
