# Project 1989 v1.9.3 Beta 1 — Startup flow fixes

- Season Review no longer fails because of a missing `cupClub` function. Historical cup winners and non-league opponents are displayed safely.
- Season Review tolerates old save entries with missing cup or play-off details.
- **New Game** added to the main navigation, and to Save / Load. Choose one of three football worlds and a club.
- Starting a new career requires confirmation when an existing game is loaded. **Export your old career first.**
- Save / Load now gives current instructions rather than references to v0.1.
- Save schema unchanged; public GitHub build is unaffected.
