# Project 1989 v1.18.0 — Under the Floodlights

- **Matchday programme export:** Save the illustrated front cover as PNG (1200 × 1698 pixels) or a two-page PDF (front cover plus match notes) directly in the browser. No server or external image service required.
- **Keep in Scrapbook:** One-click collection of the currently available home programme, even for ordinary fixtures. The saved item retains its stadium snapshot and appears in the Scrapbook programme cuttings. Special fixtures continue to be collected automatically; duplicate IDs are prevented.
- **Historical programme snapshots:** A collected edition uses the stand/terrace state at the time it was issued. An archived edition can still be exported after future stadium expansion.
- **Under the Floodlights:** Match-highlight pitch now has club-ground atmosphere: old rooflines, terrace colours, two light pylons on evening games and visible extra stands from upgrades. Each user's league match records the home venue, match timing and ground state before play; later alterations don't rewrite it.
- **Compatibility:** Existing saves supported. Earlier matches without a ground snapshot continue with the currently available stadium fallback. No match outcome, morale, attendance or financial rules changed.
- **Export implementation:** PNG rasterised from an original SVG design, PDF assembled offline from two JPEG-rendered programme pages. Browser download uses Blob/ObjectURL; programme remains playable without downloads.

All artwork is original stylised vector work; historical architecture and capacity caveats remain in development documentation, not the game interface.
