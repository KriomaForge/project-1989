# Project 1989 v1.20.0 — Managers With Personalities

- Preserves v1.19 richer national, regional and fan editorials.
- AI managers have persistent names, character styles and meeting records.
- A modest deterministic end-of-season turnover mechanic can replace the manager at the bottom club in each division.
- Appointments create newspaper stories, remain stable in JSON saves, and appear in manager career notes.
- Match previews now show managerial record and appointment history where tracked.
- Every opposition manager is an original game character, not a verified historical manager.
- Old career saves initialise the new tracker lazily without changing squads or results.
