# Project 1989 — The Club and The Crowd | v1.13.0 (Scrapbook Beta)

The first release in the Club and The Crowd roadmap.

- Manager’s Scrapbook added to the original ring-bound notebook and desk navigation.
- Uses existing managerial match records, season newspaper editions, honours, rivalries, transfers and job departures.
- Filter cuttings by honours, seasons, matches, rivalries and more.
- Existing saves and the four career modes remain supported; no new save schema is required.
- No made-up match results, fabricated stadium photographs or unverified historical ground claims.
- Older saves can only display historic details they retained.
- The actual match engine, ratings, cashflows and existing newspaper systems are unchanged.
- Stadium-specific images, supporter confidence, attendance upgrades and construction are scheduled for later milestones.

## Local testing

From the folder containing `index.html`, run `py -m http.server 8000`, then open `http://localhost:8000`.
Go to **Notebook → SCRAPBOOK**, or **Manager’s Desk → Manager’s Office → The Scrapbook**.
