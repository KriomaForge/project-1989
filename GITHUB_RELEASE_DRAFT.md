### Tester instructions
Download the **public-safe generated-player build**, extract all files, run `py -m http.server 8000`, visit http://localhost:8000 (or publish the static files on GitHub Pages).
Before updating, export any career JSON using Save / Load.
Try multiple clubs across the four divisions, advance through at least one season, inspect newspapers and opposition manager updates, and report inconsistencies with the club/week/mode.

### Data and licensing
**Do NOT attach the private 92-club historical research ZIP to a public GitHub release.** 11v11-derived player data has not been cleared for redistribution. The public-safe tester package excludes that data and historical-player modes. See SOURCES_AND_RIGHTS.md.
